# Business Park Management System

A business park management dashboard built with React, TypeScript and Redux Toolkit.

## Overview

This project is a web-based management system designed to help administrators manage tenants, rooms, contracts, maintenance requests and billing records within a business park environment.

## Tech Stack

* React
* TypeScript
* Redux Toolkit
* React Router
* Axios
* Ant Design
* Vite

## Features

* User Authentication
* Protected Routes
* Tenant Management
* Room Management
* Contract Management
* Billing Management
* Maintenance Management
* Form Validation
* Search and Filtering
* Pagination
